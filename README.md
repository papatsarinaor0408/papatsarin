# ระบบพิจารณาอนุมัติแผนพัฒนาบุคลากร ประจำปีงบประมาณ 2570

เว็บแอปหน้าเดียว (static site) สำหรับสรุปแผนพัฒนาบุคลากร/หลักสูตรที่แต่ละหน่วยงานเสนอ
ให้ผู้บริหารพิจารณากลั่นกรองได้ครบในหน้าจอเดียว พร้อมกราฟดูข้อมูลได้หลายมิติ

## ใช้งานอย่างไร

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (double-click ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องต่ออินเทอร์เน็ต)
   หรือจะโฮสต์เป็นเว็บไซต์ปกติ (GitHub Pages / เว็บเซิร์ฟเวอร์ภายในองค์กร) ก็ได้เช่นกัน
2. กด **"นำเข้าข้อมูล"** ที่มุมขวาบน แล้วเลือกไฟล์ Excel (`.xlsx`) ที่ Export มาจากระบบของหน่วยงาน
   — คอลัมน์ที่รองรับตรงกับไฟล์จริงที่ใช้ทดสอบ (ดูรายการทั้งหมดใน `assets/js/schema.js`)
3. ระบบจะจับคู่คอลัมน์ให้อัตโนมัติ ทุกแผนจะเริ่มที่สถานะ **"รอพิจารณา"**
4. ไปที่แท็บ **"พิจารณาแผนรายฉบับ"** คลิกแต่ละแผนเพื่อดูรายละเอียดทั้งหมด (หน่วยงาน ประเภท
   งบประมาณ วัตถุประสงค์ ผลลัพธ์ที่คาดหวัง ฯลฯ) แล้วกดปุ่ม **เห็นชอบ / เห็นชอบแต่ให้ทบทวน / ไม่เห็นชอบ**
   พร้อมระบุหมายเหตุ
5. แท็บ **"ภาพรวม"** และ **"สรุปตามหน่วยงาน"** จะอัปเดตสรุปผล กราฟ และอัตราการเห็นชอบให้อัตโนมัติ
6. กด **"ส่งออกผลพิจารณา (CSV)"** เพื่อได้ไฟล์สรุปผลการพิจารณากลับไปเก็บ/ส่งต่อ

## ข้อมูลอยู่ที่ไหน (สำคัญ)

- ไฟล์ที่นำเข้าจะถูกอ่าน**ในเบราว์เซอร์ของผู้ใช้เท่านั้น** ไม่มีการอัปโหลดไปที่เซิร์ฟเวอร์ใดๆ ทั้งสิ้น
- ข้อมูลที่นำเข้า และผลการพิจารณา จะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ เท่านั้น —
  หากต้องการให้ผู้บริหารหลายคน/หลายเครื่องเห็นผลเดียวกัน ให้ export CSV แล้วส่งต่อ หรือ deploy
  บนเซิร์ฟเวอร์กลางแล้วให้ทุกคนนำเข้าไฟล์เดียวกัน
- **จงใจไม่ใส่ข้อมูลจริงของหน่วยงาน (รวมถึงชื่อ-นามสกุลพนักงาน) ลงใน repository นี้** เพราะเป็น
  ข้อมูลส่วนบุคคล — สิ่งที่ผูกมากับ repo คือ "ข้อมูลตัวอย่าง" ที่สมมติขึ้นทั้งหมด (`assets/js/sampleData.js`)
  สำหรับสาธิตหน้าตาแดชบอร์ดก่อนนำเข้าไฟล์จริง
- ถ้านำเข้าไฟล์เดิมซ้ำ ระบบจะจับคู่รหัสแผนตามลำดับแถวในไฟล์ ผลการพิจารณาเดิมจะยังอยู่ **ตราบใดที่
  ลำดับแถวในไฟล์ไม่เปลี่ยน** — ถ้าไฟล์มีการเรียงลำดับใหม่ ให้ export ผลเดิมเป็น CSV เก็บไว้ก่อน

## โครงสร้างไฟล์

```
index.html                  หน้าเว็บหลัก
assets/css/style.css        ดีไซน์ (รองรับ light/dark)
assets/js/schema.js         นิยามคอลัมน์ที่ import/export และสถานะการพิจารณา
assets/js/sampleData.js     ข้อมูลตัวอย่าง (สมมติทั้งหมด) ไว้สาธิตก่อนนำเข้าไฟล์จริง
assets/js/importer.js       ตัวอ่านไฟล์ Excel/CSV (ทำงานฝั่งเบราว์เซอร์)
assets/js/charts.js         กราฟ SVG (โดนัท / แท่งซ้อน / แท่งแนวนอน) แบบไม่พึ่งไลบรารีภายนอก
assets/js/app.js            state, ตัวกรอง, การพิจารณา/อนุมัติ, สรุปตามหน่วยงาน
assets/js/vendor/xlsx.*     ไลบรารี SheetJS (อ่านไฟล์ Excel) — แนบไว้ในเครื่อง ไม่พึ่ง CDN
```

## สิ่งที่ทำได้ในหน้าจอ

- **ภาพรวม**: การ์ดสรุปจำนวนแผนแยกตามสถานะ, สัดส่วนสถานะ, สัดส่วนประเภทหลักสูตร/ปัจจัยนำเข้าหลัก,
  จำนวนแผนต่อหน่วยงานแยกตามสถานะ, งบประมาณรวมต่อหน่วยงาน — ปรับมุมมองหน่วยงานได้เป็นระดับ
  ฝ่าย/กอง/แผนก และกรองได้ทุกมิติ (หน่วยงาน/ประเภท/ปัจจัยนำเข้า/สถานะ/คำค้นหา)
- **พิจารณาแผนรายฉบับ**: ตารางค้นหา/กรองได้ คลิกเพื่อเปิดรายละเอียดเต็มของแต่ละแผนและตัดสินใจ
- **สรุปตามหน่วยงาน**: ตารางสรุปจำนวนที่เสนอ/เห็นชอบ/ให้ทบทวน/ไม่เห็นชอบต่อหน่วยงาน พร้อม
  อัตราการเห็นชอบ และรายละเอียดประเภทแผนเมื่อคลิกขยายแถว
