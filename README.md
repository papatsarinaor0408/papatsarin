# ระบบพิจารณาแผนพัฒนาบุคลากร (โรงไฟฟ้าบางปะกง) ปี 2570

เว็บแอปสำหรับสรุปแผนพัฒนาบุคลากร/หลักสูตรที่แต่ละหน่วยงานเสนอ ให้ผู้บริหารพิจารณากลั่นกรองได้ครบในหน้าจอเดียว
พร้อมกราฟดูข้อมูลได้หลายมิติ — ต้อง **Login** ก่อนใช้งาน และข้อมูลทั้งหมดเก็บไว้ใน **ฐานข้อมูลกลางออนไลน์**
(Supabase) ให้ผู้บริหารทุกคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์

## สำหรับผู้ดูแลระบบ / ฝ่าย IT

Front-end เป็น static site (ไม่มี build step) โฮสต์บน **GitHub Pages** ส่วนฐานข้อมูล/ระบบ Login/สิทธิ์
การใช้งานอยู่บน **Supabase** (Postgres + Auth + Row Level Security) — ต่างจากเวอร์ชันแรกที่เป็น
static ล้วนและไม่ต้องต่ออินเทอร์เน็ต **เวอร์ชันนี้ต้องมีอินเทอร์เน็ตเชื่อมต่อ Supabase ตลอดเวลาที่ใช้งาน**

**รองรับเบราว์เซอร์:** Google Chrome และ Microsoft Edge (Chromium-based) รุ่นใหม่ — ไม่รองรับ
Internet Explorer

**สิทธิ์การใช้งาน:**
- **Admin** (เลขประจำตัว `596203` เท่านั้น): ทำได้ทุกอย่างที่ Reviewer ทำได้ บวก Import/Replace
  ชุดข้อมูล, ล้างผลพิจารณาทั้งหมด, ดู Audit Log
- **Reviewer** (พนักงานคนอื่นทั้งหมด): ดู Dashboard, กรองข้อมูล, เปิดดูรายละเอียดแผน, บันทึกผลพิจารณา
  (เห็นชอบ/ทบทวน/ไม่เห็นชอบ) — นำเข้า/ลบชุดข้อมูลไม่ได้

สิทธิ์ทั้งหมดถูกตรวจสอบซ้ำที่ฐานข้อมูล (Row Level Security) ไม่ใช่แค่การซ่อนปุ่มที่หน้าเว็บ

รายละเอียดสถาปัตยกรรม, Edge Functions, ความปลอดภัย, และวิธีทดสอบหลัง deploy ดูได้ที่
[`DEPLOYMENT.md`](./DEPLOYMENT.md)

## ใช้งานอย่างไร

1. เปิดหน้า Login กรอกเลขประจำตัวและรหัสผ่าน (รหัสผ่านเริ่มต้นมาจากวันเดือนปีเกิด — ระบบจะบังคับให้ตั้ง
   รหัสผ่านใหม่ในการเข้าใช้งานครั้งแรก)
2. (เฉพาะ Admin) กด **"นำเข้าข้อมูล"** ที่มุมขวาบน แล้วเลือกไฟล์ Excel (`.xlsx`) ที่ Export มาจากระบบของ
   หน่วยงาน — คอลัมน์ที่รองรับตรงกับไฟล์จริงที่ใช้ทดสอบ (ดูรายการทั้งหมดใน `assets/js/schema.js`) การนำเข้า
   ซ้ำจะปรับปรุงแผนที่มีอยู่โดย**คงผลการพิจารณาเดิมไว้** ไม่ลบทิ้ง (จับคู่แผนด้วยผู้เสนอ+ชื่อหลักสูตร+หน่วยงาน
   ไม่ใช่ลำดับแถว) แผนที่ไม่มีในไฟล์ใหม่จะถูกนำออกจากรายการปัจจุบันแต่ประวัติยังอยู่ครบ
3. ไปที่แท็บ **"พิจารณาแผนรายฉบับ"** คลิกแต่ละแผนเพื่อดูรายละเอียดทั้งหมดแล้วกดปุ่ม
   **เห็นชอบ / เห็นชอบแต่ให้ทบทวน / ไม่เห็นชอบ** พร้อมระบุหมายเหตุ (จำเป็นเมื่อเลือกทบทวน/ไม่เห็นชอบ)
4. แท็บ **"ภาพรวม"** และ **"สรุปตามหน่วยงาน"** จะอัปเดตสรุปผล กราฟ และอัตราการเห็นชอบให้อัตโนมัติ —
   ทุกคนที่ Login เห็นข้อมูลชุดเดียวกัน อัปเดตทันทีที่มีคนพิจารณาแผนใหม่
5. กด **"ส่งออกผลพิจารณา (CSV)"** เพื่อได้ไฟล์สรุปผลการพิจารณากลับไปเก็บ/ส่งต่อ

## ข้อมูลอยู่ที่ไหน (สำคัญ)

- ไฟล์ Excel ที่นำเข้าจะถูกอ่าน**ในเบราว์เซอร์ของผู้ใช้เท่านั้น** ก่อนส่งเฉพาะข้อมูลที่จำเป็นไปบันทึกที่
  ฐานข้อมูลกลาง (Supabase) — ไม่มีการอัปโหลดไฟล์ดิบขึ้นไปที่ใด
- ผลการพิจารณาทุกรายการเก็บไว้ในฐานข้อมูลกลาง ผู้บริหารทุกคนเห็นข้อมูลเดียวกันทันที ไม่ต้อง export/import
  CSV เพื่อรวมผลอีกต่อไป
- **ไม่มีข้อมูลจริงของหน่วยงาน (ชื่อ-นามสกุลพนักงาน, วันเกิด, รหัสผ่าน) อยู่ใน repository นี้เลย** — ไฟล์
  ที่ใช้สร้างบัญชีผู้ใช้ครั้งแรกอยู่นอก repository เสมอ (ดูหัวข้อความปลอดภัยใน `DEPLOYMENT.md`)
- localStorage ของเบราว์เซอร์ใช้เก็บเฉพาะ session (โทเค็นการ login) และการตั้งค่าธีม (light/dark) เท่านั้น
  ไม่ใช่แหล่งข้อมูลหลักของแผน/ผลการพิจารณาอีกต่อไป

## โครงสร้างไฟล์

```
index.html                     แดชบอร์ดหลัก (ต้อง login ก่อน)
login.html                     หน้า Login + บังคับตั้งรหัสผ่านใหม่ครั้งแรก
assets/css/style.css           ดีไซน์ (รองรับ light/dark) รวมหน้า Login
assets/js/schema.js            นิยามคอลัมน์ที่ import/export และสถานะการพิจารณา
assets/js/importer.js          ตัวอ่านไฟล์ Excel/CSV (ทำงานฝั่งเบราว์เซอร์)
assets/js/charts.js            กราฟ SVG (โดนัท / แท่งซ้อน / แท่งแนวนอน) แบบไม่พึ่งไลบรารีภายนอก
assets/js/supabaseClient.js    การตั้งค่า Supabase client
assets/js/auth.js              Login/Logout/session gating
assets/js/permissions.js       ซ่อน/แสดงปุ่มตาม role (UI เท่านั้น)
assets/js/dataClient.js        เชื่อมต่อฐานข้อมูลกลางผ่าน Supabase
assets/js/app.js               state, ตัวกรอง, การพิจารณา/อนุมัติ, สรุปตามหน่วยงาน
assets/js/vendor/xlsx.*        ไลบรารี SheetJS (อ่านไฟล์ Excel) — แนบไว้ในเครื่อง ไม่พึ่ง CDN
assets/js/vendor/supabase-js.* ไลบรารี Supabase JS client — แนบไว้ในเครื่องเช่นกัน
supabase/migrations/           SQL schema/RLS/RPC ที่ใช้บนฐานข้อมูลจริง (ไม่มีข้อมูลจริงอยู่ในนี้)
supabase/functions/            Edge Functions (seed-accounts, reset-password)
```

## สิ่งที่ทำได้ในหน้าจอ

- **ภาพรวม**: การ์ดสรุปจำนวนแผนแยกตามสถานะ, สัดส่วนสถานะ, สัดส่วนประเภทหลักสูตร/ปัจจัยนำเข้าหลัก,
  จำนวนแผนต่อหน่วยงานแยกตามสถานะ, งบประมาณรวมต่อหน่วยงาน — ปรับมุมมองหน่วยงานได้เป็นระดับ
  ฝ่าย/กอง/แผนก และกรองได้ทุกมิติ (หน่วยงาน/ประเภท/ปัจจัยนำเข้า/สถานะ/คำค้นหา)
- **พิจารณาแผนรายฉบับ**: ตารางค้นหา/กรองได้ คลิกเพื่อเปิดรายละเอียดเต็มของแต่ละแผนและตัดสินใจ
- **สรุปตามหน่วยงาน**: ตารางสรุปจำนวนที่เสนอ/เห็นชอบ/ให้ทบทวน/ไม่เห็นชอบต่อหน่วยงาน พร้อม
  อัตราการเห็นชอบ และรายละเอียดประเภทแผนเมื่อคลิกขยายแถว
